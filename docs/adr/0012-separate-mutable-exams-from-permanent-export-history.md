# Separate mutable Exams from permanent Export History

An Exam is a mutable composition with a stable identity and a name, defaulting to “Untitled Exam”; Draft is not a separate resource or lifecycle state. Creating an Exam immediately persists a blank saved state. Its one Working Copy is continuously backed up for recovery and contains the current name, question references and presentation arrangement; Question Bank tabs are separately persisted workspace state and do not dirty the Exam. The editor distinguishes Saved, Unsaved changes backed up locally, Backing up, and Backup failed. Save replaces the saved state with the exact current Working Copy and supersedes older pending backup writes without clearing Undo; undoing afterward changes the Working Copy and makes the Exam unsaved again. Save As remains available for clean or changed Exams and is one atomic transaction: it creates an explicitly saved independent Exam whose name is the current name plus “Copy,” moves the Working Copy and current Undo history to that new identity, restores the source Exam to its last saved state with cleared history, and switches the editor; failure leaves the source and its Working Copy unchanged. Names need not be unique and no formal family relationship is retained. Discard likewise restores the saved state and clears Undo and Redo without changing current Question Bank content or Export History. Switching or closing needs a warning only when the latest backup is pending or failed. Each Exam has one Working Copy and a session-only Undo history; refresh clears Undo without losing the Working Copy, and concurrent editor tabs are unsupported.

Exams and Export Records are undeletable, except that the application silently discards an Exam when its current saved state and Working Copy are both the same blank “Untitled Exam” and it has no Export Records. Cleanup runs when leaving the Exam and during startup; changing only Question Bank tabs does not prevent it, while an unsaved rename or other Working Copy difference does. Export is blocked while Working Copy backup is unhealthy; otherwise it snapshots the Working Copy without saving it and creates a new immutable, undeletable Export Record attached to the Exam identity every time, with matching output and exact historical re-exports recorded again rather than deduplicated and no adjective-noun Version identity. Each record owns its complete exported question state and Layout Plans, shares only content-addressed Media Assets, and captures the Exam name at export time without losing the durable Exam reference. Export History supports only viewing and exact re-export; it cannot create or modify an Exam.
