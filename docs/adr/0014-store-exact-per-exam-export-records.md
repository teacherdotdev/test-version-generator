# Store exact per-Exam Export Records

Every successful export creates a distinct immutable, undeletable Export Record under its Exam, including repeated output and historical re-exports. A record retains only the format and Content Selection actually produced, together with the visible Working Copy name, a self-contained snapshot of its question presentation, and resolved Layout Plans; only content-addressed Media Assets are shared. Normal export uses `<Exam name>.<format>`, does not save the Working Copy, and is blocked for an empty Exam, unresolved required media, or unhealthy Working Copy backup; missing correctness or Question Metadata does not block it. The modal locks the editor while preparing, and the final action captures the resolved Working Copy state at that moment, refreshing stale preview first if a referenced Question changed. Re-export uses stored state without consulting the current Exam, Question Banks, or layout engine and cannot change format or Content Selection; its action names the fixed format and offers no configuration controls. Both paths prepare the complete artifact before atomically committing the record and required media, then start the download; preparation or persistence failure creates neither, while later browser cancellation does not roll history back. Exactness means equivalent recorded content and resolved structure rather than identical package bytes, and the history UI identifies events by captured Exam name, timestamp, format, Content Selection, and Question count rather than assigning Version names.
